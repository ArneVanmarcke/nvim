# Neovim Setup

## Windows

| Tool | Command / Link |
|------|---------------|
| Neovim | [nvim-win64.msi](https://github.com/neovim/neovim/releases/latest/download/nvim-win64.msi) |
| Git | `winget install -e --id Git.Git` |
| Nvim config | `git clone https://github.com/ArneVanmarcke/nvim.git %LOCALAPPDATA%\nvim` |
| Zig (C compiler / clangd) | `winget install -e --id zig.zig` |
| lua_ls | [LuaLS releases](https://github.com/LuaLS/lua-language-server/releases/latest) *(not needed)* |
| Pyright | `pip install pyright` |
| Rust + Cargo | [win.rustup.rs](https://win.rustup.rs/) |
| LLVM | [llvm-project releases](https://github.com/llvm/llvm-project/releases) |
| tree-sitter-cli | `cargo install tree-sitter-cli` |
